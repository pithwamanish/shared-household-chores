📐 The Mandatory Golden Triangle

Every single trace span, metric point, and structured log emitted by ANY tier MUST contain three canonical resource attributes:

Attribute 1
service.name
web-frontend, api-backend, caddy-proxy, db-postgres
Attribute 2
deployment.environment
development, staging, production (drives Grafana template variables)
Attribute 3
service.version
Immutable release tag or YYYYMMDD-HHMMSS-shortsha commit stamp

📦 Two-Stage CI/CD & Production Promotion

Gate 8: Decoupled Build vs Deploy, Immutable Tags & Digest Verification
Delivery Matrix
1. Automated CI Gates
  • Backend CI: Go 1.22 unit & store tests against live PostgreSQL container
  • Frontend CI: Strict TypeScript compilation (`tsc`) and Vite production build
  • Contract Audit: OpenAPI 3.1 schema and endpoint audit
  • E2E Integration: Containerized Playwright suite (11 user journeys)
Trigger: PR or commit push to main
2. Decoupled Container Delivery
  • Build Stage: Multi-stage Docker build packaging frontend and backend images
  • Immutable Stamp: Tagged with `YYYYMMDD-HHMMSS-shortsha` + `dev-latest`
  • Deploy Stage: Runtime Compose (`docker-compose.deploy.yml`) pulls pre-built image with zero compiler overhead
make deploy-dev (Pre-built image runtime)
3. Manual Prod Promotion
  • "Build Once, Promote Everywhere": Never recompile images for production
  • Digest Verification: Captures SHA256 immutable digest of running dev container
  • Re-tag & Serve: Re-tags digest as `prod-latest` and deploys to production cluster
make promote-prod (Digest immutability)
