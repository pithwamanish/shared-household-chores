## Operating Principle

> **The model may reason; the system must observe, authorize, verify, and remember.**

In an AI-native operational loop, a generative AI model (running in headless mode as an on-call responder) acts as the first line of triage. However, **a model's confidence never substitutes for permission**. general production credentials and direct database write access are strictly withheld. Telemetry observation, policy enforcement, command execution, and recovery verification are carried out entirely by code outside the model.

```text
change
  │
  ▼
observe user impact (OpenTelemetry → Prometheus, Loki, Tempo, Grafana)
  │
  ▼
alert with context (Alertmanager: HighHttpErrorRate)
  │
  ▼
investigate from evidence (collect-evidence.sh: bounded read-only packet)
  │
  ▼
model reasoning behind structured schema (responder-task.md → response.schema.json)
  │
  ▼
authorize bounded response outside model (autonomy-policy.yaml: Level 1 vs 2 vs 3)
  │
  ▼
execute command (rollback.sh) & verify recovery (verify-recovery.sh)
  │
  ▼
audit code & response trail (Semgrep SAST + capability-table.md + audit-trail.log)
```
